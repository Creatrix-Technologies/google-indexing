Questions

Is this allowed for my pages?

Google officially supports the Indexing API only for pages with JobPosting or BroadcastEvent structured data. For other pages a submission asks Google to crawl sooner but cannot guarantee indexing. Status checks and fix explanations work for every page.

The checker says my page can be indexed. Why isn't it in Google?

Indexable means nothing blocks Google, not that Google chose to index it. The usual fix is more unique content, internal links, and asking Google to crawl it.

Does the checker show whether my page is in Google now?

No. Only Search Console knows. Connect your site and we check every page with Google for you.

Does it work for existing pages?

Yes. Submit new pages and updated ones.

Which platforms are supported?

Any site with public URLs: WordPress, Shopify, nopCommerce, Next.js or custom.
